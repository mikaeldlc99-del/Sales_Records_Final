**clonar repositorio desde github

Opción 1: Directo desde la interfaz visual de VS Code (Más fácil)

1. Abre Visual Studio Code (en una ventana nueva o cierra la carpeta del proyecto anterior con Ctrl + K seguido de F).
2. Presiona Ctrl + Shift + P para abrir la paleta de comandos arriba.
3. Escribe Git: Clone y presiona Enter.
4. Haz clic en Clone from GitHub (o pega la URL completa de tu repositorio: https://github.com).
5. Selecciona la carpeta en tu computadora donde guardas tus proyectos (por ejemplo, Documentos o Desktop) y haz clic en Select as Repository Destination.
6. Cuando termine (tarda 2 segundos), haz clic en el botón azul Open que aparece abajo a la derecha.


Opción 2: Por terminal en VS Code

1. Abre una terminal en VS Code (Ctrl + ñ) ubicada en la carpeta donde guardas tus proyectos (fuera de tu proyecto anterior).
